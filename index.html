    From mix to race

    1. Generate your mix and copy the code.
    2. In Dolphin, right-click the game → Properties → AR Codes → Add. Name it, paste the code, save and enable it.
    3. Enable Config → General → Enable Cheats. Turn off any previous last-place or item-replacement code.
    4. Stop emulation and start the game again. Start a multiplayer GP or VS race.

    A few things to know

    This generator targets the original USA disc, GM4E01 revision 0. It generates a Dolphin AR code locally; your game file is never uploaded or changed.

    Weights apply when the item roulette finishes, based on the kart’s position at that moment. Golden Mushrooms keep their normal timed duration.

    Compatibility & testing notes

    Executable verified against Mario Kart - Double Dash!! (USA)(2).iso: USA GM4E01 revision 0. Its executable matches the previously checked CISO, including the hook and unused space for the patch.

    The selection routine is checked against this executable, including every item ID and table boundary. The prior patch passed a single-player race-start check; this generator’s new routine and arbitrary special-item combinations have not been verified in live multiplayer.

    The code keeps the game’s original item pools unless Maximum Bananas is enabled. Active-item limits may affect whether a selected item can be equipped or used. Maximum Bananas adds Ralf’s USA banana-limit codes; this combined configuration has not been tested in a live race. Avoid combining it with other item, allocation or code-cave patches.

    Fireballs and eggs are grouped by their shared game item IDs. Loose projectiles, empty slots and battle-only objects are not roulette items.
